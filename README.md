# ☕ Brew Bliss – Coffee Ordering Android App

A modern coffee app UI developed using Kotlin and Jetpack Compose, focused on a smooth, intuitive, and visually appealing Android user experience.

## ✨ Features

- Modern coffee welcome screen
- Coffee product listing with images and prices
- Coffee categories and product discovery
- Interactive product cards
- Navigation between app screens
- Clean, reusable Jetpack Compose UI components

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Navigation:** Navigation Compose
- **IDE:** Android Studio
- **Platform:** Android

## 🚀 Future Enhancements

- User authentication with Firebase
- Shopping cart and order management
- Backend API integration
- Secure payment integration
